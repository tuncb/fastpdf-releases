# FastPDF

A native Windows PDF reader. Open local PDFs, navigate pages and bookmarks,
search and copy text, rotate and zoom pages, and print.

This repository contains public releases, downloads, and release notes.

## Download

Open [Releases](https://github.com/tuncb/fastpdf-releases/releases) and download
**fastpdf.exe**. Run it directly. No installer, extraction step, or companion
file is required. The app requires Windows 10 version 1703 or later on x64.

Each release includes **SHA256SUMS.txt** to check the executable's SHA-256 hash.
Third-party notices are embedded in the app under
**Help → About… → Third-party notices…**.

## Install and update

Use **Install FastPDF** on the welcome screen or **Help → Installation…** to
install for your Windows account. You can also continue with a portable copy.

Installed copies can check for updates through **Help → Check for updates…**.
FastPDF checks only when requested and verifies downloads before installation.

Older copies that check **tuncb/fastpdf** need one manual download from this
repository. Close all FastPDF windows and replace the existing **fastpdf.exe**
with the new file. Installed copies are in **%LOCALAPPDATA%\Programs\FastPDF**.
Your PDFs and settings are retained.

GitHub's **Source code** ZIP and TAR downloads contain this release repository's
files. Download **fastpdf.exe** to use the app.
